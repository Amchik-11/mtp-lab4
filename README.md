## Среднее №3: сумма через reduce

В `calculations.py` функция `add_numbers` использует `functools.reduce`
и функцию `operator.add`. Начальное значение свёртки — ноль.

```python
from calculations import add_numbers

print(add_numbers([12, 8, -3, 5]))  # 22
print(add_numbers([]))             # 0
```

Принимается итерируемый источник целых чисел, включая одноразовый итератор.
`map` проверяет элементы по мере чтения. Исходный список не изменяется;
строки, дробные и логические значения отклоняются. Встроенная `sum`
в реализации не используется.

## Среднее №5: генератор Фибоначчи

`streams.fibonacci_numbers(size)` выдаёт ровно `size` элементов через `yield`.
Начало последовательности: 0, 1, 1, 2, 3, 5. Хранится только пара соседних
чисел; полный список заранее не вычисляется.

```python
from streams import fibonacci_numbers

sequence = fibonacci_numbers(6)
print(next(sequence))    # 0
print(list(sequence))    # [1, 1, 2, 3, 5]
```

Размер означает количество элементов, а не верхнюю границу значений.
После последнего элемента генератор завершается. Нулевой размер допустим,
отрицательный и нецелый — нет.

## Среднее №9: случайные числа в диапазоне

`streams.numbers_in_range(start, stop, size, seed=None)` — конечный генератор
целых чисел. Начальная и конечная границы включены.

```python
from streams import numbers_in_range

print(list(numbers_in_range(10, 30, 6, seed=17)))
# [26, 23, 19, 21, 19, 15]
```

Если границы совпадают, выдаётся это значение. При размере 0 поток пустой.
Начало не может быть больше конца. Для каждого экземпляра создаётся
свой `random.Random`; одинаковый seed позволяет повторить результат,
глобальное состояние random остаётся неизменным.

У функций seed по умолчанию равен `None`. В командной строке выбран seed 17
для воспроизводимых примеров, его можно поменять через `--seed`.

## Повышенное №3: каррирование

`currying.curry_three` превращает функцию трёх позиционных аргументов
в цепочку трёх вызовов по одному аргументу:

```python
from currying import curry_three, reading_volume

for_five_sessions = curry_three(reading_volume)(5)
for_twenty_pages = for_five_sessions(20)
print(for_twenty_pages(2))  # 5 * (20 - 2) = 90
print(for_twenty_pages(4))  # 5 * (20 - 4) = 80
```

`reading_volume(sessions, pages, skipped)` вычисляет
`sessions * (pages - skipped)` и служит арифметическим примером.
Можно передать другую функцию трёх аргументов, в том числе строковую:

```python
label = curry_three(lambda prefix, word, suffix: prefix + word + suffix)
print(label("[")("книга")("]"))  # [книга]
```

Первые два вызова возвращают замыкания. Исходная функция выполняется
только при передаче третьего аргумента. Промежуточные функции можно
использовать повторно, их состояние не изменяется.
Это именно цепочка `f(a)(b)(c)`, а не обычный вызов `f(a, b, c)`.

Область реализации явно ограничена тремя позиционными аргументами.
Совместимость сигнатуры и значений проверяется исходной функцией при
последнем вызове; несовместимая сигнатура приводит к `TypeError`.
Каждый этап принимает ровно один аргумент. Обёртка не подавляет
исключения исходной функции.

## Повышенное №7: бесконечные случайные данные

`streams.sensor_data(seed=None)` моделирует показания датчика. Каждый вызов
`next` возвращает новый словарь с номером записи, температурой от -10 до 35
градусов (один знак после точки) и влажностью от 0 до 100 процентов.

```python
from itertools import islice
from streams import sensor_data

sensor = sensor_data(seed=17)
for record in islice(sensor, 3):
    print(record)
print(next(sensor)["sequence"])  # 4
```

Первый элемент при seed 17:
`{'sequence': 1, 'temperature': 13.5, 'humidity': 38}`.

Внутри — `while True` и `yield`, собственного ограничения длины нет.
В примерах используется `islice`, поэтому запуск завершается. Нельзя
превращать весь бесконечный поток в список без ограничения.
Изменение выданного словаря не влияет на следующие записи.
Поток использует отдельный экземпляр random и не влияет на другие потоки.
Данные псевдослучайные и предназначены для учебного примера.
